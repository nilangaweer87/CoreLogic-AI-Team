# CoreLogic Studios AI Team

14 AI roles covering 23 finance, digital, creative, legal-document, payroll and hospitality services. These are internal AI roles, not licensed professionals or human employees.

## Start

Open [BOOTSTRAP.md](BOOTSTRAP.md), attach it to the existing MausBot assistant/Chief, and ask: "Create the CoreLogic Studios team from this file, install the included skills where supported, and run the synthetic delegation test. Preserve the experimental team until the replacement is verified."

This is a single-file instruction bundle for MausBot's supported team tools, not a native import-format claim. Skill installation and tool connections can require separate app review. No API key is included.

## Files

- [Member settings](members/): every member's fields and standing instructions.
- [Skills](skills/): one independently shareable SKILL.md folder per member.
- [Service coverage](service-routing.md): all 23 services.
- [Organisation and workflow](organisation.md).
- [Checks](VALIDATION.md): static checks and remaining live tests.
- team-manifest.json: portable source data; do not overwrite MausBot's bots.json with it.

## Tools and scope

Connect only tools needed for the current client/project. A skill does not install software, provide subscriptions, authenticate Canva, provision hosting or grant system permissions. Use Chrome for browser work. Keep public repository content generic; keep client records, credentials, payroll and private contracts elsewhere.

## Replacing the experiment

First verify the new roster, actual delegation, skill status and deliverables. Preserve a private recovery copy where supported. Old-team deletion removes chat/memory/skills and is separate from creation; obtain the required app confirmation at that step. Never delete unrelated client work or the executing Chief. Local experimental identities belong in a private retirement checklist, not this public repository.
